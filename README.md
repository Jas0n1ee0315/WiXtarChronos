# WiXtarChronos（星益欣打卡）

星益欣 HR 系統的 Android 手機端與 Wear OS 手錶端整合應用，提供線上打卡、補打卡、請假單申請（含附件上傳）、出勤表查詢與桌面快速捷徑等功能。

---

## 主要功能

### 1. 線上打卡
- 即時同步當日上班／下班打卡紀錄，支援一鍵打卡。
- 跨日凌晨 `00:00` 自動重置當日打卡狀態。
- 手機端與 Wear OS 手錶端資料同步（含手錶 Tile 狀態更新）。

### 2. 補打卡（對應 `B3.7.線上補刷卡`）
- 顯示當日刷卡時間與當日應出勤時間。
- 選擇「進卡」或「出卡」與日期／時間，選擇「忘記打卡」時會依進出卡別自動對應系統代碼（`A` / `B`）。
- 補登原因選擇「其他因素(請註明原因)」時，備註欄為必填。
- 送出前跳出確認視窗，送出後顯示系統稽核結果（含重複補登攔截提示）。

### 3. 請假單（對應 `B2.1.請假單`）
- **假別餘額顯示**：自動載入當年度特休與當月加班補休時數資訊。
- **支援假別**（預設為特休）：
  - 特休、事假、半薪病假、無薪病假、生日假、公假、家庭照顧假、外訓假、公傷病假、工出、加班補休、陪產檢及陪產假-給予七天、喪假 (天)、喪假 (時)、婚假、謀職假、歲時祭儀假。
- **動態條件欄位**：
  - 選擇 **喪假 (天)** 或 **喪假 (時)** 時，動態顯示必選的親屬關係「說明」下拉選單。
  - 選擇 **陪產檢及陪產假-給予七天**、**喪假 (天)**、**喪假 (時)** 或 **婚假** 時，動態顯示必填的「特殊日期」。
  - 請假「起始日期」早於今日時，動態顯示並強制填寫「逾期請假原因」。
  - 「請假說明」為必填欄位。
- **職務代理人整合**：提供唯讀下拉選單選擇已設定的代理人；若尚未設定，點擊該欄可直接跳轉至設定中的「職務代理人」頁面。
- **兩段式確認檢視與附件上傳**：
  1. 先向 HR 系統檢核並試算「本次請假時間合計」。
  2. 進入確認明細頁核對後，可選取最多 5 個證明文件附件（如訃聞、診斷證明等），透過 `multipart/form-data` 一併送出存檔。

### 4. 出勤表（對應 `B4.1.考勤彙總表`）
- 支援自訂查詢日期區間與下拉更新。
- 提供「顯示種類」篩選：**每天**（預設）、**遲到**、**曠職**、**異常**。
- 點擊任一日期卡片可檢視詳細出勤明細（班別、進／出卡、工時、請假、加班、異常等）。

### 5. 系統設定（右上角齒輪圖示）
- **打卡驗證資訊**：設定工號、密碼與自動登入（Cookie / `enc` 過期自動續期）。
- **多位職務代理人設定**（對應 `A2.夥伴資料查詢`）：輸入工號查詢同仁姓名與部門並儲存多位代理人；多於一位時可點擊星號切換預設代理人，或移除不需要的代理人。
- **推播通知與 Wear OS 整合**：支援上下班提醒與手錶同步開關。

### 6. 桌面快速捷徑（App Shortcuts）
- 長按桌面 APP 圖示即可快速開啟：
  - **線上打卡**
  - **補打卡**
  - **請假單**
  - **出勤表**

### 7. 桌面小工具（App Widgets）
- 提供多種桌面 Widget 尺寸與造型（`1x1` 方形／圓形、`2x1` 標準／膠囊 Stadium、`Circle` 圓形、`4x1`），並支援**標準**與**半透明**樣式。
- 可於手機桌面直接顯示當日上班／下班打卡時間並點擊快速打卡，跨日凌晨 `00:00` 自動重置。

### 8. 手機快捷設定磚（Quick Settings Tile）
- 支援將「WiXtar 打卡」加入 Android 系統下拉快捷設定面板，無需開啟主畫面即可檢視狀態或觸發打卡。

### 9. Wear OS 手錶端與手錶 Tile
- 提供獨立 Wear OS 手錶應用程式與 **手錶 Tile**，可於錶面直接滑動切換至打卡卡片檢視當日進／出卡時間並一鍵打卡。
- 支援與手機端雙向同步打卡狀態，並同樣具備跨日凌晨 `00:00` 自動重置與 Tile 即時更新。

## 專案模組結構

- `:mobile` — Android 手機端應用程式（Jetpack Compose + Material 3）
- `:app` — Wear OS 手錶端應用程式與 Tile
- `:core` — 共用資料層（`AppStorage`、HR 網路請求 `ClockRepository`、資料模型與同步工具）

## 下載與建置

### 下載 APK
可前往 [GitHub Releases](https://github.com/Jas0n1ee0315/WiXtarChronos/releases) 下載已打包的 Debug APK（`WiXtarChronos-mobile-debug.apk` 與 `WiXtarChronos-wear-debug.apk`）。

### 本機建置指令

```bash
# 建置手機端 Debug APK
./gradlew :mobile:assembleDebug

# 建置手錶端 (Wear OS) Debug APK
./gradlew :app:assembleDebug
```
